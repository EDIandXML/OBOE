# Getting Started with OBOE

## Adding the dependency

### Maven
```xml
<dependency>
    <groupId>com.ediandxml</groupId>
    <artifactId>oboe</artifactId>
    <version>2026.04.08</version>
</dependency>
```

### Gradle
```groovy
implementation 'com.ediandxml:oboe:2026.04.08'
```
