# HIPAA Specific Features

OBOE has built-in support for HIPAA EDI transactions (5010 and later).

## Supported Transactions

- 837 (Professional, Institutional, Dental)
- 835 (Remittance Advice)
- 834 (Enrollment)
- 270/271 (Eligibility)

## Key HIPAA Features

- Automatic validation of HIPAA-specific code sets
- Loop ID handling
- Situational rules support
